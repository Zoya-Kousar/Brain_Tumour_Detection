Brain Tumor Detection Using Machine Learning
This project aims to automatically detect brain tumors from MRI images using machine learning. It utilizes the YOLOv10 object detection algorithm for accurate tumor localization and classification. The workflow includes image preprocessing, feature extraction, and model evaluation using metrics like accuracy, precision, and recall.

Features:
Preprocessing of MRI images

Feature extraction for tumor detection

YOLOv10 object detection for classification

Evaluation with accuracy, precision, and recall metrics
